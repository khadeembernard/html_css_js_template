# Student HTML & CSS Starter Template

Welcome to your starter template! This project is designed to give you a clean, modern, and accessible foundation for building your first websites. It uses best practices for web development without relying on complicated frameworks or tools.

## Getting Started

You don't need any special software to run this project! To get started:

1. **Download the file:** Save `index.html` to a folder on your computer.
2. **View the site:** Double-click `index.html` to open it in your web browser (Chrome, Firefox, Safari, Edge, etc.).
3. **Edit the code:** Open `index.html` in a code editor like [VS Code](https://code.visualstudio.com/), Notepad++, or Sublime Text. 
4. **See your changes:** Whenever you save changes in your code editor, just refresh your web browser to see the updates!

## Features included

This template comes packed with modern web development features to help you learn:

* **Single-File Structure:** The CSS (styles) and HTML (structure) are currently in one file to make it easy to start. *(Challenge: Try moving the CSS into its own `style.css` file!)*
* **Semantic HTML:** We use tags like `<header>`, `<main>`, `<article>`, and `<footer>` instead of just using `<div>` for everything. This helps with accessibility (screen readers) and SEO (search engines).
* **CSS Variables (Custom Properties):** At the top of the `<style>` section, you'll see a `:root` block. Change the `--primary-color` here, and watch it update everywhere on the site!
* **Flexbox & CSS Grid:** The layout uses modern CSS techniques. The navigation uses Flexbox to space out links, and the main layout uses CSS Grid to create a sidebar next to the main content.
* **Responsive Design:** Try resizing your browser window! The template includes a `@media` query that automatically stacks the layout on smaller screens (like mobile phones).

## Things to Try (Your Homework!)

Once you have the template open, try making these changes to test your skills:

1. **Change the Theme:** Find `--primary-color: #2563eb;` in the CSS and change the hex code to your favorite color (e.g., `#ff0000` for red or `#10b981` for green).
2. **Add Content:** Swap out the dummy text (Lorem ipsum) for a real blog post, an "About Me" section, or a review of your favorite movie.
3. **Add an Image:** Try adding an `<img src="...">` tag inside one of the articles. Use a free image from [Unsplash](https://unsplash.com/).
4. **Add a New Link:** Add a new `<li><a href="#">Contact</a></li>` to the navigation bar.
5. **Change Fonts:** Look up Google Fonts and try importing a new font for the headings!
