Welcome to Your New Website

This template is built using semantic HTML5 tags. These tags tell the browser and screen readers exactly what kind of content they contain, making your site more accessible and better for search engines (SEO).

Try modifying the CSS variables in the <style> block to completely change the color scheme of this page in just a few keystrokes!

How to Use This Template

1. Copy the code into your own `.html` file.

2. Read through the comments in the CSS to understand how Flexbox and CSS Grid are working together.

3. Add your own content inside the <article> tags and see how the page reacts when you resize your browser window.
